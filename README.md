# 🍃 MongoDB Mastery — Shell Queries, Data Modeling & Core Concepts

A comprehensive learning repository documenting **hands-on practice with MongoDB using Mongo Shell (`mongosh`)**.  

This repo captures the **practical journey** of learning MongoDB fundamentals, advanced queries, data modeling, and aggregation — **without relying on application code**.

Focus: Understanding **how MongoDB works internally** through direct shell interaction.

---

## 🎯 Objective of This Repository

- Learn MongoDB by writing **real querie's in mongosh**  
- Understand **NoSQL data modeling**  
- Practice **CRUD, filtering, projection, and updates**  
- Master the **Aggregation Framework**  
- Learn **indexing and performance basics**  
- Build a **strong backend database foundation**
